# Papyrus: product tour

- **First launch.** Opens straight into a sample note explaining the basics; no tour.
- **Create a note.** Large "New note" button at the bottom of the sidebar. The cursor lands in the body; the title is the first line.
- **Formatting.** A fixed toolbar above the editor; no Markdown shortcuts.
- **Share a note.** "Share" button next to the title; one dialog with "can view" or "can edit".
- **Find a note.** Search is a separate screen, opened from the magnifier icon; titles only unless "search in content" is ticked.
- **Offline.** Read-only offline.
- **Pricing for teams.** 5 USD per user per month.
